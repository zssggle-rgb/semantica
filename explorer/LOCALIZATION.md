# Explorer 中文化

本分支基于官方 Semantica 0.7.0（`2a9afec685fe6f4a18350834caed3d6a9affb27a`）。中文修改只涉及原生前端，后台 API 与图谱数据模型沿用官方实现。

## 使用

页面左侧底部选择“中文 / English”。首次打开使用浏览器语言，随后记住所选语言；也可在当前 URL 加 `lang=zh-CN` 或 `lang=en-US`。

切换语言重新加载页面。用户已明确不要求保留切换前的未保存编辑，本分支没有为此增加保护流程。

## 文案维护

- `src/i18n/en-US.json`、`zh-CN.json` 使用原始英文文案作为翻译键；标点和变量占位符必须与调用一致。
- `uiText()` 只处理软件自身的界面文案。不要传入任意用户资料、查询语句、类型标识或编辑后的图谱对象。
- 共用术语：本体、对象类型、实例、对象关系、数据属性、适用类型、取值类型、来源依据、数据追溯。
- 动态值通过 `{{v0}}` 等占位符插入，不翻译标识和用户值。
- 保留原始数据、协议名、文件格式和后台原始诊断。剩余的前端自有英文文案应补译。

## 构建与部署

沿用官方入口，在 `explorer/` 安装锁文件中的依赖并运行 `npm run build`。生成 `../semantica/static/`，同时带入 Monaco 原生代码编辑器及中文资源；使用页面时不从外部 CDN 下载编辑器。

Monaco 0.55.1 的中文 AMD 模块名为 `vs/nls.messages.zh-cn.js`，包内文件名为 `nls.messages.zh-cn.js.js`。构建和开发服务为原生文件提供单扩展名别名，内容不变；AMD `baseUrl` 指向后台已有的 `/assets/monaco/` 挂载目录。

将完整 `semantica/static/` 部署到同版本原生 Python 服务的静态目录。保持后台、图谱文件、认证、主机绑定与数据库不变。替换前保留原版静态目录；回退只需恢复它。

GitHub 源码：https://github.com/zssggle-rgb/semantica 。本分支以 `upstream-v0.7.0` 为 PR 基线，便于只查看该版本的中文修改。

## 验收范围

源码 review、逐工作区中文覆盖核对，以及本体编辑、图谱查看、导入导出主操作。已有本体与来源资料保留原值，不重新提炼知识。

本任务不运行全量测试或 CI，不测试切换时保留未保存编辑；不借中文化修改原生后台、MCP 或持久化机制。
